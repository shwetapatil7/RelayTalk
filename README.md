# RelayTalk 💬

## About the Project

RelayTalk is a full-stack real-time chat application developed to provide users with a platform for instant online communication.

The application allows users to create an account, log in securely, and communicate through a chat interface. It is designed with a separate frontend and backend, making the application easier to develop and maintain.

The **frontend** provides the user interface for authentication, conversations, profiles, settings, and chat functionality. The **backend** handles server-side operations, authentication, and communication with the database.

The project uses **MongoDB** for data storage. The frontend is developed using React.js, Vite, Tailwind CSS, and Axios, while the backend is built using Node.js and Express.js.

## Features

- User registration and login
- Real-time messaging
- One-to-one conversations
- User profiles
- Online/offline user status
- Chat interface
- Theme customization
- Responsive user interface
- Secure authentication
